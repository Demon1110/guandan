# 素材授权清单

本文件是 `R10` 的执行台账：每一份进入仓库的素材（牌面、音效、字体、UI 图标）都在此登记来源与授权方式，M1 前必须全表可查。

全部自研就不需要授权了吧



## 收录规则

1. 允许收录。
2. 每份素材登记原始下载地址与授权页快照日期，授权文本存于 `docs/assets/license/<素材ID>.txt`（正文 + 抓取时间），随仓库入库。
3. 字体单独成节，因为中文字体的商用授权最容易出问题。
