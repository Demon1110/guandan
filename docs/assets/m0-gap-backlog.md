## 4. 一句话口径

`REJECT unknown field / unknown variant` = schema 没有位（§3）；`OK 但文档要求的行为没发生` = 校验或执行层欠债（§2）。两类从不混记——把校验没做记成"设计缺失"，会让本可以补校验的活被当成要改设计的活；反过来把设计缺失当实现债补，等于实现期自行发明契约。
